# Hardware Components

| Component | Purpose |
|---|---|
| Arduino Uno | Main control unit |
| Flame Sensor | Fire detection |
| Servo Motor | Directs water spray |
| L298N Motor Driver | Controls DC motor speed/direction |
| ESP32 | Environmental monitoring and IoT capability |
| DHT11 | Temperature and humidity |
| MQ-2 | Smoke/combustible gas detection |
| MQ-135 | Air-quality monitoring |
| OLED | Displays environmental readings |
| Relay Module | Electrically controlled switching |
| 4-wheel Chassis | Mechanical base and mobility |
| Water Pump + Tank | Fire extinguishing |
| Batteries | Portable power |

**Note:** The project presentation does not specify final GPIO pin assignments. Add the tested pin map after confirming the actual circuit.
