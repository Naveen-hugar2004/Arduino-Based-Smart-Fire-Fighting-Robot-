# Project Description

## Introduction
Fire accidents can threaten human life, property and the environment. Delayed detection can increase damage and risk.

FireSense Rover combines fire detection and firefighting with environmental monitoring. Arduino Uno performs fire detection, navigation and water-based extinguishing. ESP32 monitors temperature, humidity, gas and air quality.

## Problem Statement
Industrial zones, laboratories, storage facilities and remote areas can be difficult or unsafe for manual fire monitoring. The project aims to detect fire sources, respond automatically and continuously monitor environmental conditions.

## Objectives
- Develop an autonomous fire-fighting rover using Arduino Uno and flame sensors.
- Implement water-based fire extinguishing using a pump and servo motor.
- Monitor temperature, humidity, smoke and gas using ESP32.
- Enable autonomous navigation toward a fire source.
- Coordinate Arduino and ESP32 functions.
- Apply robotics, embedded systems and IoT to safety.
