# Working Methodology

1. **Fire Detection:** Flame sensors monitor the surroundings.
2. **Processing:** Arduino Uno processes the sensor signals.
3. **Navigation:** The rover moves toward the detected fire source.
4. **Fire Extinguishing:** The servo aims the spray and the water pump supplies water.
5. **Environmental Monitoring:** ESP32 reads DHT11, MQ-2 and MQ-135 sensors.
6. **Display:** OLED shows temperature, humidity, gas and air-quality readings.
7. **IoT Extension:** ESP32 can be extended for wireless/remote monitoring.
